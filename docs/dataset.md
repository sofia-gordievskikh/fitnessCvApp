# Сбор датасета

Датасет собирался из коротких видео и фото упражнений: приседания, выпады,
наклоны, стойка боком и фронтально. Нужны были кадры, где тело частично
перекрывается руками или спортивным инвентарем.

## Разметка

Классы:

- `head`;
- `torso`;
- `left_arm`;
- `right_arm`;
- `left_leg`;
- `right_leg`.

Формат для обучения YOLO segmentation:

```text
data/processed/body_parts_yolo/
  images/train
  images/val
  labels/train
  labels/val
  data.yaml
```

Разметка делалась полигонами по частям тела. Для быстрых тестов часть кадров
размечалась bbox, но финальный train использовал segmentation labels.

## Split

- train: примерно 70%;
- val: примерно 20%;
- test: примерно 10%.

Важно было не класть соседние кадры одного видео в разные split, иначе метрики
получались слишком красивые.
