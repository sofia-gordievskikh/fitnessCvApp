# Примеры разметки и правила

Короткий гайд, как размечали части тела, чтобы разметка была одинаковой у разных
людей. Полигоны рисовали в CVAT, экспорт в YOLO segmentation формат.

## Формат метки

Одна строка на объект:

```text
<class_id> x1 y1 x2 y2 ... xn yn   # нормированные координаты полигона
```

`class_id`:

```text
0 head
1 torso
2 left_arm
3 right_arm
4 left_leg
5 right_leg
```

## Правила

### Левая / правая сторона

Сторона определяется **со стороны спортсмена**, а не зрителя. Если человек стоит
к нам лицом, его левая рука визуально справа на кадре.

```text
кадр (вид спереди):

   [right_arm]   torso   [left_arm]
       |          | |        |
   right_leg              left_leg
```

Это главный источник ошибок, поэтому при сомнении смотрим на голову/лицо и
определяем ориентацию тела.

### Перекрытия

- Размечаем **видимую** часть. Если рука закрывает кусок корпуса, torso в этом
  месте обрываем, полигон руки идёт поверх.
- Не дорисовываем невидимые части «по воображению».
- Если две части сливаются в один пиксельный ком (тёмная одежда, тень) - режем
  по анатомической границе (плечо, бедро, талия).

### Инвентарь

Штанга, гантели, резинки - **не размечаем** и не включаем в руки. Если инвентарь
перекрывает конечность, конечность обрываем на границе инвентаря.

### Плохие кадры (в датасет не берём)

- сильный motion blur, тело нечитаемо;
- обрезано больше одной крупной части (нет обеих ног);
- несколько людей в кадре (пока только один субъект);
- экстремальная засветка/темнота.

Такие кадры складываем в `data/raw/rejected/`, чтобы не размечать повторно.

## Мини-пример

Синтетические демо-кадры лежат в `samples/`. Это НЕ обучающие данные, а заглушки
для запуска пайплайна без реального датасета - силуэт из простых фигур. Реальная
разметка делается по фото, а не по этим кадрам.
